# YJ Furniture

English furniture and carpentry portfolio, supplied as self-contained HTML.

## Publish with GitHub Pages

In the repository, open Settings → Pages. Choose **Deploy from a branch**, select the branch containing these files and **/ (root)**, then Save.

## Files

- `index.html`: customer-facing, read-only portfolio with embedded logo and images.
- `editor.html`: editable portfolio; data is stored only in the current browser.
- `.nojekyll`: serves the site as plain static files.

## Update your portfolio

1. Open `editor.html` and choose **Edit website**.
2. Add project images, contact details and company information. Save your changes.
3. Click **Export customer HTML**.
4. Rename the exported file to `index.html` and replace this repository's `index.html` with it.

Local browser edits do not automatically update GitHub or other visitors' views. Keep exported copies as backups. The editor is a local editing tool, not an authenticated admin panel. Visitors cannot modify the repository through it.

Project photos and contact details have not yet been supplied. The initial skill percentages and company description should be reviewed by the owner.
